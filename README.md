## Controls

| Action                   | Keys       |
| ------------------------ | ---------- |
| Move                     | ← →        |
| Soft drop                | ↓          |
| Hard drop                | Space      |
| Rotate clockwise         | ↑, X       |
| Rotate counter-clockwise | Z, L Ctrl  |
| Rotate 180°              | A          |
| Hold                     | C, L Shift |
| Pause                    | Esc, P     |



## Install


```sh
git clone https://github.com/fredrir/rstris
cd rstris
bun install
bun tauri build
```
